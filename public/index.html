ARQUITECTURA ORIENTADA A SERVICIOS

Una plataforma gamer compuesta por servicios especializados.

La interfaz web consume una API REST. Cada dominio —catálogo, biblioteca, logros, torneos, reseñas, perfil, notificaciones y analítica— tiene lógica separada y responsabilidades claras.
