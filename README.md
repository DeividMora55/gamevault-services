# GameVault Services — interfaz pública

Esta carpeta contiene una versión web funcional para GitHub Pages.

## Qué muestra
- Dashboard
- Catálogo
- Biblioteca
- Lista de deseos
- Logros
- Torneos
- Reseñas
- Notificaciones
- Analítica
- Perfil

Los datos de demostración se conservan en `localStorage`, por lo que las acciones funcionan en GitHub Pages sin servidor Node.js.

## Publicación
Sube `index.html`, `styles.css`, `app.js`, `manifest.webmanifest` y `service-worker.js` a la raíz del repositorio.

En GitHub:
Settings → Pages → Deploy from a branch → `main` → `/(root)`.

La URL se mantiene:
https://deividmora55.github.io/gamevault-services/
